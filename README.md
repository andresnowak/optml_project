# Optimization for Machine Learning (CS-439) Project

This repository contains the code for the "Optimization for Machine Learning" course for the 2026 Spring Semester at EPFL.
The scope of this project is to analyze how the SpecMuon optimizer ([Source](https://arxiv.org/abs/2602.16167)) works, exploring its usage across different problems and settings.
